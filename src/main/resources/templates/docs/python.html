파이썬에서 성경 API 쓰기

개역개정 성경 구절을 파이썬에서 불러오는 방법입니다. 표준 라이브러리만으로도 되고, requests 를 쓰면 더 짧습니다.

1. 준비

메인 페이지에서 API 키를 발급받습니다. 모든 요청에 X-API-KEY 헤더로 넣습니다.

pip install requests

2. 구절 하나 가져오기

GET/api/verse
import requests

API_KEY = "발급받은_키"
BASE_URL = "https://logos-api.com"

def random_verse():
    response = requests.get(
        f"{BASE_URL}/api/verse",
        headers={"X-API-KEY": API_KEY},
        timeout=5,
    )
    response.raise_for_status()
    return response.json()

verse = random_verse()
print(verse["reference"], verse["text"])

4. 참조로 바로 찾기

GET/api/verse?ref=요3:16

약어와 정식 이름을 모두 받습니다. 절을 지정하지 않으면 그 장 전체가 배열로 옵니다.

def by_reference(ref):
    response = requests.get(
        f"{BASE_URL}/api/verse",
        params={"ref": ref},
        headers={"X-API-KEY": API_KEY},
        timeout=5,
    )
    if response.status_code == 400:
        raise ValueError("참조 형식을 읽을 수 없습니다: " + ref)
    if response.status_code == 404:
        raise LookupError("해당 구절이 없습니다: " + ref)
    response.raise_for_status()
    return response.json()

print(by_reference("요3:16"))        # 구절 하나
print(by_reference("요3:16-18"))     # 세 구절
print(len(by_reference("시23")))     # 시편 23편 전체 절 수

5. 구절 검색

GET/api/search?q=사랑&limit=20&offset=0

본문에 검색어가 들어간 구절을 정경 순서로 돌려줍니다. 응답의 books 는 책마다 몇 건인지를 건수가 많은 순으로 담습니다.

def search(keyword, book=None, limit=20, offset=0):
    params = {"q": keyword, "limit": limit, "offset": offset}
    if book:
        params["book"] = book

    response = requests.get(
        f"{BASE_URL}/api/search",
        params=params,
        headers={"X-API-KEY": API_KEY},
        timeout=5,
    )
    response.raise_for_status()
    return response.json()

result = search("사랑")
print(result["total"], "건")
for verse in result["results"]:
    print(verse["reference"], verse["text"])

7. 오류와 속도 제한

상태뜻대응
401키가 없거나 폐기됨메인 페이지에서 재발급
400검색어가 2자 미만, 참조 형식 오류입력값 확인
404해당 구절 없음참조 확인
429요청이 너무 잦음 (IP당 분당 60회)X-RateLimit-Retry-After 초만큼 대기
 
import time

def call_with_retry(path, params=None, retries=3):
    for attempt in range(retries):
        response = requests.get(
            f"{BASE_URL}{path}",
            params=params,
            headers={"X-API-KEY": API_KEY},
            timeout=5,
        )
        if response.status_code != 429:
            response.raise_for_status()
            return response.json()

        wait = int(response.headers.get("X-RateLimit-Retry-After", 1))
        time.sleep(wait)
    raise RuntimeError("요청 한도를 넘었습니다")
