Logos API 문서

개역개정 성경 구절을 무료로 제공하는 REST API입니다.

1. API 개요

Base URLhttps://logos-api.com
형식JSON
기계용 스펙/v3/api-docs (OpenAPI 3.1). Postman 이나 코드 생성기에서 주소만 넣으면 엔드포인트가 한 번에 들어옵니다
이용 조건무료 · 비상업적 이용
운영시간08:00 ~ 22:00 (KST) · 운영시간 외에는 응답이 지연되거나 제공되지 않을 수 있습니다

2. 키 발급

  1. 메인 페이지에서 API 키 발급받기 버튼을 누릅니다.

4. 랜덤 구절 · 참조 조회

GET/api/verse
GET/api/verse?ref=요3:16
파라미터필수설명
ref아니오참조 표기. 없으면 무작위 구절을 돌려줍니다
표기뜻응답
요3:16요한복음 3장 16절 (약어)구절 1개
요한복음 3:16정식 이름도 됩니다구절 1개
요3:16-1816절부터 18절까지배열
요33장 전체배열

약어는 창 출 삼상 고전 살후 요일처럼 통용되는 66권 표기를 씁니다. 형식을 읽을 수 없으면 400, 해당 구절이 없으면 404로 응답합니다. 참조 조회 응답은 내용이 고정이라 하루 캐싱되고, 무작위 구절은 3초만 캐싱됩니다.

curl

curl -H "X-API-KEY: your_api_key_here" https://logos-api.com/api/verse

JavaScript

const apiKey = 'your_api_key_here';

    fetch('https://logos-api.com/api/verse', {
        method: 'GET',
        headers: { 'X-API-KEY': apiKey }
    })
    .then(res => res.json())
    .then(data => console.log(data.text));

Java

HttpClient client = HttpClient.newHttpClient();
    HttpRequest request = HttpRequest.newBuilder()
            .uri(URI.create("https://logos-api.com/api/verse"))
            .header("X-API-KEY", "your_api_key_here")
            .GET()
            .build();

    HttpResponse<String> response =
            client.send(request, HttpResponse.BodyHandlers.ofString());

응답

{
      "book": "골로새서",
      "chapter": "3",
      "verse": "23",
      "text": "무엇을 하든지 마음을 다하여 주께 하듯 하고 사람에게 하듯 하지 말라",
      "reference": "골로새서 3:23"
    }

5. 오늘의 말씀 조회

매일 자정 기준으로 고정된 한 구절을 반환합니다. 같은 날엔 누가 호출해도 같은 구절이 나옵니다.

GET/api/verse/today

파라미터가 없습니다. 같은 날에는 누가 호출해도 같은 구절을 돌려줍니다.

curl

curl -H "X-API-KEY: your_api_key_here" https://logos-api.com/api/verse/today

JavaScript・Java 호출 방식은 위 랜덤 구절 예제와 동일합니다 — URL만 /api/verse/today로 바꾸면 됩니다.

응답

{
      "book": "시편",
      "chapter": "23",
      "verse": "1",
      "text": "여호와는 나의 목자시니 내게 부족함이 없으리로다",
      "reference": "시편 23:1"
    }

6. 책 · 장 · 절 조회

특정 책과 장을 지정해 구조적으로 탐색할 수 있습니다.

경로 파라미터설명
book책 이름. 정식 이름만 받습니다 (예: 요한복음). 등록되지 않은 책이면 빈 배열
chapter장 번호. 숫자가 아니면 400, 없는 장이면 빈 배열

책 목록

GET/api/books
curl -H "X-API-KEY: your_api_key_here" https://logos-api.com/api/books
["창세기", "사도행전", "..."]

장 목록

GET/api/books/{book}/chapters
curl -H "X-API-KEY: your_api_key_here" https://logos-api.com/api/books/사도행전/chapters
[1, 2, 3, 4, 5]

절 목록

GET/api/books/{book}/chapters/{chapter}
curl -H "X-API-KEY: your_api_key_here" https://logos-api.com/api/books/사도행전/chapters/1
[
      {"verse": "1", "text": "..."},
      {"verse": "2", "text": "..."}
    ]

JavaScript・Java 호출 방식은 위 랜덤 구절 예제와 동일합니다 — URL만 바꾸면 됩니다.

7. 구절 검색

GET/api/search?q=사랑&book=요한1서&limit=20&offset=0
파라미터필수설명
q예검색어. 2자 이상 100자 이하. 본문에 그대로 포함된 구절을 찾습니다
book아니오특정 책으로 좁힙니다. 등록되지 않은 책 이름은 400
limit아니오한 번에 받을 건수. 기본 20, 최대 50
offset아니오건너뛸 건수. 기본 0

curl

curl -H "X-API-KEY: your_api_key_here"       "https://logos-api.com/api/search?q=%EC%82%AC%EB%9E%91&limit=2"

응답

{
      "query": "사랑",
      "total": 557,
      "offset": 0,
      "limit": 2,
      "books": { "창세기": 13, "시편": 32, "요한1서": 30 },
      "results": [
        {
          "book": "창세기",
          "chapter": "22",
          "verse": "2",
          "text": "여호와께서 이르시되 네 아들 네 사랑하는 독자 이삭을 데리고 ...",
          "reference": "창세기 22:2"
        }
      ]
    }

books는 책마다 검색어가 몇 번 나오는지를 건수가 많은 순으로 담습니다. book 필터와 무관하게 항상 전체 기준이라, 어느 책을 볼지 고르는 데 쓸 수 있습니다. 결과는 정경 순서(창세기 → 요한계시록) · 장 · 절 순으로 정렬됩니다. 웹에서는 구절 검색 페이지로 바로 쓸 수 있습니다.

8. 오류 응답

오류는 모두 JSON으로 돌려주며 error 키를 공통으로 담습니다.

상태언제응답
400검색어가 2~100자가 아님, 등록되지 않은 책 이름, 참조 형식을 읽을 수 없음, 장 번호가 숫자가 아님{"error": "Bad Request", "message": "..."}
401X-API-KEY 헤더가 없거나 폐기된 키{"error": "API Key is missing"} / {"error": "Invalid API Key"}
404참조가 가리키는 구절이 없음, 없는 주소{"error": "Not Found", "message": "..."}
429요청이 너무 잦거나(9번) 키 발급 일일 한도 초과{"error": "Too Many Requests", "retry_after_seconds": 42}
500서버 오류{"error": "Internal Server Error"}

예시

curl -H "X-API-KEY: your_api_key_here"       "https://logos-api.com/api/verse?ref=요한복음"

    HTTP/1.1 400 Bad Request
    {
      "error": "Bad Request",
      "message": "참조 형식을 읽을 수 없습니다. 예: 요3:16, 요한복음 3:16-18, 요3"
    }

429 응답에는 X-RateLimit-Retry-After 헤더로 다시 시도할 수 있는 시간(초)이 함께 옵니다. 정상 응답에는 X-Rate-Limit-Remaining 으로 남은 요청 수가 옵니다.
