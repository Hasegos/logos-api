Logos API 문서

개역개정 성경 구절을 무료로 제공하는 REST API입니다. 아래 안내에 따라 바로 연동해보세요.

1. API 주소

GET https://logos-api.com/api/verse

2. 키 발급

  1. 메인 페이지에서 새 키 발급하기 버튼을 누릅니다.
  2. 발급 시 기존 키는 즉시 폐기되며, 동일 IP 기준 하루 10회로 제한됩니다.
키 발급하러 가기 →

3. 인증 방법

모든 요청에는 아래 헤더가 필요합니다.

KeyValue
X-API-KEY발급받은 UUID

4. 요청 예제

curl

curl -H "X-API-KEY: your_api_key_here" https://logos-api.com/api/verse

JavaScript

const apiKey = 'your_api_key_here';

fetch('https://logos-api.com/api/verse', {
    method: 'GET',
    headers: { 'X-API-KEY': apiKey }
})
.then(res => res.json())
.then(data => console.log(data.text));

Java

import java.net.URI;
import java.net.http.HttpClient;
import java.net.http.HttpRequest;
import java.net.http.HttpResponse;

public class LogosApiTest {
    public static void main(String[] args) throws Exception {
        HttpClient client = HttpClient.newHttpClient();
        HttpRequest request = HttpRequest.newBuilder()
                .uri(URI.create("https://logos-api.com/api/verse"))
                .header("X-API-KEY", "your_api_key_here")
                .GET()
                .build();

        HttpResponse<String> response =
                client.send(request, HttpResponse.BodyHandlers.ofString());
    }
}

6. 속도 제한 정책

키 발급동일 IP 기준 하루 10회
API 호출과도한 트래픽은 서버 단에서 제한됩니다
캐싱동일 응답에 대해 3초간 브라우저 캐싱 적용

7. 라이선스 및 데이터 고지

성경 텍스트는 개역개정(KRV) 판을 기반으로 하며, 저작권은 대한성서공회 등 해당 권리자에게 있습니다. 교육 및 개인 묵상 목적으로만 사용해 주세요. 자세한 내용은 GitHub 저장소의 LICENSE를 참고하세요.
