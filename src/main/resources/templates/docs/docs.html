Logos API 문서

개역개정 성경 구절을 무료로 제공하는 REST API입니다.

1. API 개요

Base URLhttps://logos-api.com
형식JSON
이용 조건무료 · 비상업적 이용

2. 키 발급

  1. 메인 페이지에서 API 키 발급받기 버튼을 누릅니다.
  2. 발급 시 기존 키는 즉시 폐기되며, 동일 IP 기준 하루 10회로 제한됩니다.

4. 랜덤 구절 조회

GET /api/verse

curl

curl -H "X-API-KEY: your_api_key_here" https://logos-api.com/api/verse

JavaScript

const apiKey = 'your_api_key_here';

    fetch('https://logos-api.com/api/verse', {
        method: 'GET',
        headers: { 'X-API-KEY': apiKey }
    })
    .then(res => res.json())
    .then(data => console.log(data.text));

Java

HttpClient client = HttpClient.newHttpClient();
    HttpRequest request = HttpRequest.newBuilder()
            .uri(URI.create("https://logos-api.com/api/verse"))
            .header("X-API-KEY", "your_api_key_here")
            .GET()
            .build();

    HttpResponse<String> response =
            client.send(request, HttpResponse.BodyHandlers.ofString());

응답

{
      "book": "골로새서",
      "chapter": "3",
      "verse": "23",
      "text": "무엇을 하든지 마음을 다하여 주께 하듯 하고 사람에게 하듯 하지 말라",
      "reference": "골로새서 3:23"
    }

5. 오늘의 말씀 조회 신규

매일 자정 기준으로 고정된 한 구절을 반환합니다. 같은 날엔 누가 호출해도 같은 구절이 나옵니다.

GET /api/verse/today

curl

curl -H "X-API-KEY: your_api_key_here" https://logos-api.com/api/verse/today

JavaScript・Java 호출 방식은 위 랜덤 구절 예제와 동일합니다 — URL만 /api/verse/today로 바꾸면 됩니다.

응답

{
      "book": "시편",
      "chapter": "23",
      "verse": "1",
      "text": "여호와는 나의 목자시니 내게 부족함이 없으리로다",
      "reference": "시편 23:1"
    }

6. 책 · 장 · 절 조회 신규

특정 책과 장을 지정해 구조적으로 탐색할 수 있습니다.

책 목록

GET /api/books
curl -H "X-API-KEY: your_api_key_here" https://logos-api.com/api/books
["창세기", "사도행전", "..."]

장 목록

GET /api/books/{book}/chapters
curl -H "X-API-KEY: your_api_key_here" https://logos-api.com/api/books/사도행전/chapters
[1, 2, 3, 4, 5]

절 목록

GET /api/books/{book}/chapters/{chapter}
curl -H "X-API-KEY: your_api_key_here" https://logos-api.com/api/books/사도행전/chapters/1
[
      {"verse": "1", "text": "..."},
      {"verse": "2", "text": "..."}
    ]

JavaScript・Java 호출 방식은 위 랜덤 구절 예제와 동일합니다 — URL만 바꾸면 됩니다.

7. 속도 제한 정책

키 발급동일 IP 기준 하루 10회
API 호출과도한 트래픽은 서버 단에서 제한됩니다
캐싱랜덤 구절 조회는 3초간 브라우저 캐싱 적용
