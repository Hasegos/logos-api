자바스크립트에서 성경 API 쓰기

개역개정 성경 구절을 자바스크립트에서 불러오는 방법입니다. fetch 하나면 되고, 추가 라이브러리가 필요 없습니다.

1. 준비

메인 페이지에서 API 키를 발급받습니다. 모든 요청에 X-API-KEY 헤더로 넣습니다.

브라우저에서 직접 부르지 마세요. 키가 사용자에게 그대로 노출되고, 교차 출처 요청은 허용되지 않습니다. 아래 5번처럼 서버에서 중계하세요.

2. 구절 하나 가져오기

GET/api/verse
const BASE_URL = 'https://logos-api.com';
const API_KEY = process.env.LOGOS_API_KEY;

async function randomVerse() {
  const response = await fetch(`${BASE_URL}/api/verse`, {
    headers: { 'X-API-KEY': API_KEY },
  });

  if (!response.ok) {
    throw new Error(`호출 실패: ${response.status}`);
  }
  return response.json();
}

const verse = await randomVerse();
console.log(verse.reference, verse.text);

3. 참조로 바로 찾기

GET/api/verse?ref=요3:16

약어와 정식 이름을 모두 받습니다. 절을 지정하지 않으면 그 장 전체가 배열로 옵니다.

async function byReference(ref) {
  const url = new URL(`${BASE_URL}/api/verse`);
  url.searchParams.set('ref', ref);

  const response = await fetch(url, { headers: { 'X-API-KEY': API_KEY } });

  if (response.status === 400) throw new Error(`참조 형식 오류: ${ref}`);
  if (response.status === 404) throw new Error(`구절 없음: ${ref}`);
  if (!response.ok) throw new Error(`호출 실패: ${response.status}`);

  return response.json();
}

await byReference('요3:16');      // 구절 하나
await byReference('요3:16-18');   // 세 구절
await byReference('시23');        // 시편 23편 전체

4. 구절 검색

GET/api/search?q=사랑&limit=20&offset=0
async function search(keyword, { book, limit = 20, offset = 0 } = {}) {
  const url = new URL(`${BASE_URL}/api/search`);
  url.searchParams.set('q', keyword);
  url.searchParams.set('limit', limit);
  url.searchParams.set('offset', offset);
  if (book) url.searchParams.set('book', book);

  const response = await fetch(url, { headers: { 'X-API-KEY': API_KEY } });
  if (!response.ok) throw new Error(`호출 실패: ${response.status}`);
  return response.json();
}

const result = await search('사랑');
console.log(`${result.total}건`);
result.results.forEach((v) => console.log(v.reference, v.text));

books 는 책마다 몇 건인지를 건수가 많은 순으로 담습니다. 책 필터와 무관하게 전체 기준이라 필터 UI를 만들 때 바로 쓸 수 있습니다.

5. Node.js 서버에서 중계하기

키를 숨기려면 서버가 대신 부르고 결과만 내려 줍니다. Express 예시입니다.

import express from 'express';

const app = express();

app.get('/verse/today', async (req, res) => {
  try {
    const response = await fetch('https://logos-api.com/api/verse/today', {
      headers: { 'X-API-KEY': process.env.LOGOS_API_KEY },
    });
    res.status(response.status).json(await response.json());
  } catch (e) {
    res.status(502).json({ error: 'Bad Gateway' });
  }
});

app.listen(3000);

오늘의 말씀은 날짜 기준으로 고정되므로, 서버에서 하루 한 번만 부르고 캐시해도 됩니다.

6. 오류와 속도 제한

상태뜻대응
401키가 없거나 폐기됨메인 페이지에서 재발급
400검색어가 2자 미만, 참조 형식 오류입력값 확인
404해당 구절 없음참조 확인
429요청이 너무 잦음 (IP당 분당 60회)X-RateLimit-Retry-After 초만큼 대기
 
async function callWithRetry(path, params = {}, retries = 3) {
  const url = new URL(`${BASE_URL}${path}`);
  Object.entries(params).forEach(([k, v]) => url.searchParams.set(k, v));

  for (let attempt = 0; attempt < retries; attempt++) {
    const response = await fetch(url, { headers: { 'X-API-KEY': API_KEY } });

    if (response.status !== 429) {
      if (!response.ok) throw new Error(`호출 실패: ${response.status}`);
      return response.json();
    }

    const wait = Number(response.headers.get('X-RateLimit-Retry-After') ?? 1);
    await new Promise((resolve) => setTimeout(resolve, wait * 1000));
  }
  throw new Error('요청 한도를 넘었습니다');
}
