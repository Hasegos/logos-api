자바에서 성경 API 쓰기

개역개정 성경 구절을 자바에서 불러오는 방법입니다. JDK 11부터 들어간 HttpClient 만으로 되고, 스프링에서는 RestClient 가 더 짧습니다.

1. 준비

메인 페이지에서 API 키를 발급받습니다. 모든 요청에 X-API-KEY 헤더로 넣습니다. 의존성은 없어도 됩니다.

2. 구절 하나 가져오기

GET/api/verse
import java.net.URI;
import java.net.http.HttpClient;
import java.net.http.HttpRequest;
import java.net.http.HttpResponse;
import java.time.Duration;

public class LogosClient {

    private static final String BASE_URL = "https://logos-api.com";
    private static final String API_KEY = "발급받은_키";

    private final HttpClient client = HttpClient.newBuilder()
            .connectTimeout(Duration.ofSeconds(5))
            .build();

    public String randomVerse() throws Exception {
        HttpRequest request = HttpRequest.newBuilder()
                .uri(URI.create(BASE_URL + "/api/verse"))
                .header("X-API-KEY", API_KEY)
                .GET()
                .build();

        HttpResponse<String> response =
                client.send(request, HttpResponse.BodyHandlers.ofString());

        if (response.statusCode() != 200) {
            throw new IllegalStateException("호출 실패: " + response.statusCode());
        }
        return response.body();
    }
}

3. 스프링에서는 RestClient

import org.springframework.web.client.RestClient;

@Service
public class BibleService {

    private final RestClient restClient = RestClient.builder()
            .baseUrl("https://logos-api.com")
            .defaultHeader("X-API-KEY", "발급받은_키")
            .build();

    public VerseResponse today() {
        return restClient.get()
                .uri("/api/verse/today")
                .retrieve()
                .body(VerseResponse.class);
    }

    public VerseResponse byReference(String ref) {
        return restClient.get()
                .uri(builder -> builder.path("/api/verse").queryParam("ref", ref).build())
                .retrieve()
                .body(VerseResponse.class);
    }
}

public record VerseResponse(String book, String chapter, String verse,
                            String text, String reference) {
}

ref 에 절 범위(요3:16-18)나 장 전체(시23)를 주면 응답이 배열이므로 List<VerseResponse> 로 받습니다.

4. 구절 검색

GET/api/search?q=사랑&limit=20&offset=0
public SearchResponse search(String keyword, int limit, int offset) {
    return restClient.get()
            .uri(builder -> builder.path("/api/search")
                    .queryParam("q", keyword)
                    .queryParam("limit", limit)
                    .queryParam("offset", offset)
                    .build())
            .retrieve()
            .body(SearchResponse.class);
}

public record SearchResponse(String query, int total, int offset, int limit,
                             Map<String, Integer> books,
                             List<VerseResponse> results) {
}

books 는 책마다 몇 건인지를 건수가 많은 순으로 담습니다. 책 필터와 무관하게 전체 기준입니다.

6. 오류와 속도 제한

상태뜻대응
401키가 없거나 폐기됨메인 페이지에서 재발급
400검색어가 2자 미만, 참조 형식 오류입력값 확인
404해당 구절 없음참조 확인
429요청이 너무 잦음 (IP당 분당 60회)X-RateLimit-Retry-After 초만큼 대기
 
restClient.get()
        .uri("/api/verse")
        .retrieve()
        .onStatus(status -> status.value() == 429, (request, response) -> {
            String retryAfter = response.getHeaders().getFirst("X-RateLimit-Retry-After");
            throw new IllegalStateException(retryAfter + "초 뒤에 다시 시도하세요");
        })
        .body(VerseResponse.class);
